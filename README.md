# THƯ VIỆN TRÒ CHƠI TOÁN HỌC THCS

Chào mừng thầy cô và các em học sinh!

Đây là thư viện trò chơi Toán học tương tác dành cho học sinh Trung học cơ sở.

## CÁC KHỐI LỚP

- Toán 6
- Toán 7
- Toán 8

- Trò chơi hình học

## HƯỚNG DẪN SỬ DỤNG

1. Chọn khối lớp hoặc chủ đề.
2. Chọn trò chơi muốn trải nghiệm.
3. Mở trò chơi bằng Chrome hoặc Edge.
4. Làm theo hướng dẫn trên màn hình.

## NGUYÊN TẮC

- Giao diện thân thiện với học sinh.
- Có thể sử dụng trong giờ học.
- Ưu tiên HTML5 chạy offline.
- Nội dung Toán học được kiểm tra chính xác.
